## 点击音效

`kubejs/client_scripts/mouse_click_sound.js` 监听鼠标原始按下事件。左键每次按下播放一次现有科技点击声，覆盖按钮、背包槽位、界面空白处和世界内点击。松开、持续长按、右键和中键不播放；不会取消鼠标操作。

`kubejs/assets/minecraft/sounds.json` 将原来的按钮音效条目改为独立的 `minecraft:poc_mouse_click`，继续使用同一个 OGG。客户端脚本阻止原版 `minecraft:ui.button.click` 播放，避免按钮叠加两遍，也使键盘激活按钮不再播放点击声。

### 保留的原有脚本问题

- `Click.js` 的自然精华加副手鱼竿途径定义 10% 获得鳕鱼模型，但使用了 `event.offHandItem` 和带 `#` 的 `hasTag` 参数，与常用的玩家副手取值/标签写法不同，可能无法触发。已保留该页并标注途径待确认；没有改动原事件，正常钓鱼 25% 途径另有页面。
- 雪块左键催化剂同时有 KubeJS 固定产出 1 个冰精华的事件，以及消耗雪块、50% 额外产出的 Lychee 配方，两者均保留并分别说明。
- 当前 Lychee 雷击序列化器不读取 `block_in`；原脚本中部分条目的金块字段不构成实际条件。因此新页面按命令中真正被替换的方块显示，未额外要求金块。
