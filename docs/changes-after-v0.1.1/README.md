# v0.1.1 之后的开发更新

整理日期：2026-10-09。比较基准为正式 `v0.1.1` 标签（`1059b75e872360a588198f96c1b3c5d37801e6fc`），范围包括此后 Git 提交及本次同步的本地项目文件。

该页记录 v0.1.1 之后的前期开发变化，相关内容已纳入 **v2.0**。新版本还包含 47 个 JEI 展示配方、左键音效完善、第三章更名与星核光标；完整发布说明见 [v2.0](../releases/v2.0/README.md)。临时 v0.1.2 测试发布已经下架。

## 玩家可见的变化

### 界面与加载页

- 统一深色青蓝科技风格：覆盖生存背包、创造背包三页、原版工作台与箱子、按钮和输入框、JEI、Crafting Tweaks、Extended Crafting 四级手动工作台及终极合成界面。
- 优化任务书背景、章节侧栏、节点、连线和完成状态；降低网格亮度，改善章节文字对比度和勾选显示。
- 增加快捷栏底板、选中框、副手槽和攻击指示装饰，并同步 JourneyMap 小地图边框与方向标记素材。
- 主菜单与世界选择页增加分组面板、轨道、刻度、品牌铭牌和电路细节；修正主菜单背景配置，继续使用整合包图片背景。
- 新增四类世界加载页面的原创机械方块背景和双语阶段面板。能取得真实进度的阶段显示进度条与百分比，其余阶段使用扫描动画。
- UI 素材由 KubeJS 自动加载，加入资源优先级兼容补丁；修复不可修改资源列表导致的启动崩溃。新增实例无需另行选择 UI 资源包。

主要文件：`kubejs/assets/`、`config/fancymenu/`、`mods/kubejs_lang_override-1.21.1-neoforge-1.0-poc.jar`。设计与检查资料见 [基础 UI](../../design/ui-tech-2026-10-08/README.md)、[五页细节](../../design/ui-polish-2026-10-08/README.md)、[世界加载页](../../design/screen-polish-2026-10-08/README.md)。

### 专属光标与音效

- 新增轻量客户端光标模组：金属与电路风格箭头，左、右、中键分别显示不同颜色的点击光环。
- 修复切换 FTB 任务页或章节后专属光标丢失；保留文本、手形、拖动及缩放等特殊光标，提供光标和点击动画开关。
- 加入主菜单舒缓电子纯音乐《虚空初光 / Void Dawn》，约 3 分 37 秒，循环播放，并使用游戏音乐音量设置。
- 替换共享按钮点击事件为约 100 毫秒的电子机械轻击音效，覆盖使用该事件的原版、FancyMenu 和 FTB 按钮。

详情见 [光标模组](../../tools/poc-cursor/README.md)、[菜单配乐](../../design/menu-music-2026-10-08/README.md)、[按钮音效](../../design/button-sounds-2026-10-08/README.md)。

### 任务书与语言修复

- “提示与技巧”由 17 条扩展为 36 条，补充 19 条阅读提示，并按基础操作、空岛与建筑、资源与收集、物流与自动化、能源与机器、稳定与维护六组排列。
- 同步中英文标题与说明，修正纠缠方块、天境昼夜等机制表述，补充当前整合包的操作与配置提示。新增提示没有奖励或主线依赖。
- 同步当前任务章节的布局与配置保存格式；现有任务的章节解锁依赖未改变，物品获取脚本未改变。
- 当前本地章节已移除两个独立建筑模板领取任务：第四章药水工厂（`2B4A2F4E70823F3D`）和第五章五级虚空采矿（`082A860A24936FA8`）。其他任务不依赖这两个节点；前五章任务数由 450 变为 448。内置建筑数据修复脚本仍保留，本次按现有工作文件同步这两项删除。
- 将剧情翻译初始化从服务端脚本移至启动脚本，解决新版 KubeJS 只读 `global` 环境下的初始化错误；同步语言检查工具中的脚本路径。
- 同步本地模组汉化资源包。

主要文件：`config/ftbquests/quests/`、`kubejs/startup_scripts/localization.js`、`tools/localization/check.py` 及 `resourcepacks/Minecraft-Mod-Language-Modpack-Converted-1.21.1.zip`。

## 客户端更新器

- 新增增量更新：优先选择适用于当前版本、且小于完整包的补丁；补丁不可用、损坏或基础文件不匹配时回退完整包。
- 下载界面显示实际所选包的大小。增量安装只替换变化文件并清理旧清单中移除的文件，减少重复下载、写入与备份。
- 保留 SHA-256 校验、退出游戏后安装、事务备份及回滚；保存完整目标清单供下一次增量更新使用。
- 发布流程为最近三个符合条件的较旧正式版本生成直达补丁，并附加完整目标清单；旧更新器仍能通过完整包升级。
- 临时 v0.1.2 已用于真实更新链路测试，用户反馈测试通过后下架；正式更新源已恢复 v0.1.1。

源码、协议及维护方式见 [更新器说明](../../tools/poc-updater/README.md)。
