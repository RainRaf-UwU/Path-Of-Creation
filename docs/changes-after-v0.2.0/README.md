# v0.2.0 之后的修改记录

核对日期：2026-10-23。基线为正式标签 [`v0.2.0`](https://github.com/RainRaf-UwU/Path-Of-Creation/tree/v0.2.0)，提交 `5675a0d7d63705276ced5922e8a755a81905e265`。范围包含标签之后的既有提交，以及本次同步的全部未提交项目文件。

这里记录的是开发分支变化，正式下载仍指向 v0.2.0；本次同步没有创建新版本标签或 Release。v0.2.0 已有的 47 条 JEI 展示配方、增量更新器、第三章更名和初版星核光标，不重复计为本次新增。

## 剧情与 ECHO 科技手册

- 新增仅在新建世界时触发的开场剧情：第一人称直线睁眼、视角过渡、玩家真实皮肤立绘、非人形 ECHO、逐字声音、分页和对话选择。玩家逐字声使用最终选定的 hi 短音；旧存档不补播。
- 序章正常结束后赠送 `poc_intro:tech_manual`，记录每位玩家的领取状态；异常退出与超时释放不会误发书。旧存档可以用 `/pocmanual` 找回并打开。
- 手册采用三栏界面，当前有 **52 个分类、4631 条目录、732 个操作主题、42 项实时按键和143张原模组配图**，覆盖科技模组本体与附属，也包含任务没有提及的设备。目录包含等级和颜色变体，不能把全部条目数量当成独立教程篇数。
- 支持中文、英文、物品 ID、模组族与 JEI 搜索方式，以及配方/用途跳转、长文分页、配图缩放和拖动。图文说明补充设备操作、配置、连接、常见故障与排查。
- 新增第一章结尾“第一件造物”：在现有 9×9 配方中合成并取出普通工作台后触发，支持普通取出与 Shift 合成。剧情期间冻结世界并锁定操作，结束后恢复；剧情本身不消耗工作台、不替玩家执行流体交换。
- 剧情流程可在 `config/poc-intro/chapter1.json` 编辑；正文与角色名统一使用 `kubejs/assets/rain/lang` 中英翻译键。

源码与说明：[`tools/poc-intro`](../../tools/poc-intro/README.md)、[手册内容维护](../../tools/poc-intro/manual/README.md)。

## 新增维度方阵

- 新增 **11×11×11** 自定义多方块与独立共振产物，包含控制器、装甲、框架、导轨、约束节点、4个必需的高维投影模块，以及可选能量输入/输出口、冷却液输入口。
- 能量接口共享控制器储能；冷却接口共享 64,000 mB 储罐，默认用水，可通过流体标签扩展。
- 通电后显示四维超立方体全息投影，具有渐入/渐出、惯性加速与制动、240 rpm 高速残影，以及通电、加速、高速和减速音效。
- 增加热量与冷却系统、随温度变化的颜色和抖动、渐强警报，以及运行时内部伤害。完全缺液连续运行120秒达到热量上限；60秒共振配方正常运行消耗6000 mB冷却液。
- 热失控会破坏控制器并启动分批地形清理及蘑菇云效果。破坏范围按 **11×11个水平区块、11个垂直区块节** 对齐，最大176×176×176格；基岩等不可破坏方块保留。运行时内部伤害与失控冲击也会影响创造模式玩家。
- 新增共振配方：16末影珍珠、16紫水晶碎片、4福鲁伊克斯水晶，60秒、32,768 FE/t，产出维度共振晶体；控制器、结构件和接口均有合成声明。
- 新增“整合包多方块搭建”JEI分类，读取实际结构要求，覆盖五类机器、17份图纸；支持旋转、分层、缩放、平移、材料分页与方块悬停信息。预览绘制改用适配GUI的管线。

完整结构、配方、热量参数与安装说明见 [`tools/poc-dimension-matrix`](../../tools/poc-dimension-matrix/README.md)。

## 原有多方块重设计与自动成形

- 重新布置染色工厂、虚空采矿机、流体处理机和旧结构检测器的 **16份结构声明**，保持各结构原有材料种类和数量；15份主体/检测图的控制器紧邻红石块，时间晶体附加模块与原子主体保持兼容。
- 更新7份建筑小帮手模板和8处现有任务奖励引用，一键搭建同步新结构。模板升级只替换仍与官方旧版完全一致的内容，保留玩家自行修改的模板。
- 为8套生产机器主体及时间晶体附加模块加入自动成形外观：结构完整即显示整机，无电时也保留机壳；拆坏结构后恢复原方块显示。实际方块、库存、NBT和碰撞保持原样。
- 工艺机构按实际用途设计，包括数据模型写入头、采矿钻头和分离转子、药剂混合与灌装、流体反应舱、原子再构照射头，以及预言矩阵计算机柜和结果舱；运行时启动，停机后制动，并配套机械音效。
- 增加原版与Sodium方块/方块实体/流体显示遮罩。结构检测器后续被列为废案，保留旧配方和任务，排除自动成形渲染；维度方阵继续使用独立外观。
- 修正四份原机器定义的 `name.text` 包装，避免Custom Machinery跳过机器注册。

重设计本身保持 **520条原功能配方** 的材料、产物、能量、时长及当时的优先级等声明；此前单独进行的优先级修复见下节。

## 配方、任务与兼容修复

- 导电合金任务 `07644C54930C8FAB` 从第三章移至第二章，保留原任务、奖励和物品检测ID；前置改为铜合金任务，脉冲合金任务随后依赖导电合金。
- 导电合金改用末影接口合金炉：**1铁锭 + 1铜锭 + 1红石 → 2导电合金锭**，3200能量；移除原Powah充能配方及对应全局移除项，脉冲合金配方的合金材料改为导电合金。
- 为多级虚空采矿和流体处理配方设置明确优先级，处理完整高级结构同时满足低级结构条件时，低级配方抢先匹配的问题；同步建筑模板与相关提示。
- 新增客户端模组 `poc-lychee-jei-compat`：Lychee查询JEI配方/用途前，将流动流体规范化为源流体，拒绝无效查询，修复 `Focus value is invalid` 崩溃。原Lychee/JEI JAR与世界配方保持不变。
- 更新任务与自定义内容的中英文本、JEI分类/模组顺序和汉化资源包。当前仍有578个实际任务、591条依赖，任务总数未增加。

兼容补丁说明：[`tools/poc-lychee-jei-compat`](../../tools/poc-lychee-jei-compat/README.md)。
