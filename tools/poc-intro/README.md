# 创世之径 · ECHO 剧情与科技手册

Minecraft 1.21.1 / NeoForge 21.1.255 / Java 21。运行模组为实例 `mods/poc-intro-1.0.0.jar`，完整重启游戏加载。不需要安装额外第三方模组。

使用整合包默认的 Skyblock Builder / Rain 模板创建新世界，会播放序章：黑屏、第一人称水平直线睁眼，7–9秒平滑切到第三人称前侧、坐姿环顾、ECHO 显现、逐字对话及两处回答选项。剧情不引用任务章节名称。ECHO 是非人形晶体核心。玩家发言时左下角直接渲染当前玩家真实皮肤，包含皮肤外层和宽/细手臂，微微朝右；已按原版投影修正缩放与纵向中心，保留完整头部和上半身。离线预览中的示例皮肤不代表你的实际皮肤。

鼠标左键或空格/回车继续，文字未完成时点击只加快逐字速度。选项逐字显示完后可点击，或用上下键选择、回车确认。正文过长会分页。对话与选项的每个字符均有短音；玩家使用用户指定`hirari_02.wav`中开头约80ms的hi音节，保持原音高与速度，播放音高固定1.0，不轮换元音。ECHO保持固定电子短音，两者均已提高音量。音量随游戏主音量生效。演出期间禁用角色移动、鼠标转头、物品使用和菜单；窗口失焦时文字与动画暂停。

结尾交还操作并保留生存基础飞行，双击空格起飞，空格上升、潜行下降。飞行资格保存于新世界的 `data/poc_intro.dat`，死亡、换维度和重登后恢复；不授予创造模式或无敌。正常结束后 ECHO 发放一本科技模组手册，领取 UUID 也持久化，超时/断线不发放。现有工作台和其中物品保持。

仅本次创建世界会话中的主角可以触发。世界路径和创建时的 WorldData 对象绑定内存一次性许可：旧档、首次安装后打开旧档、重进新档、剧情中断后重进、LAN 后加入者都不会补播。创建失败产生的许可也不能被旧档重开消费。独立服务器不通过客户端创建入口，不播放序章。非 Rain 模板若未提供附近终极工作台，准备阶段超时会安全释放玩家，不改造世界。

临时座位在结束、断连和退出时清理，异常退出残留的座位在下次从磁盘加载时清理。锁定期间不改变玩家无敌、重力、游戏模式或药水状态，避免中断后残留限制。加载界面有最长 120 秒的客户端就绪等待；客户端就绪后再给工作台 12 秒准备时间，避免首次世界渲染较慢时误跳过剧情。整段会话有 10 分钟安全释放上限。

序章流程在 `src/main/resources/assets/poc_intro/story.json`，其中只保留翻译键；正文、选项、角色名和界面文字统一写在实例根目录 `kubejs/assets/rain/lang/zh_cn.json` 与 `en_us.json`，键前缀为 `poc_intro.story.prologue.` 和 `poc_intro.story.chapter1.`。界面绘制在 `IntroUi.java`，游戏和离线截图共用，立绘取景共用 `PortraitFraming.java`。`assets/` 包含独立系统图标及非人形立绘SVG设计源；游戏通过几何绘制实时显示。`build-sounds.mjs`编码`assets/audio/player-hi.wav`中的80ms hi短音，并生成ECHO与确认声，共三个OGG。用户原音副本保留为`assets/audio/player-hi-source.wav`，取样与淡化说明见同目录README，原始外部文件保持不变。

构建（Node.js、Java 21，无 npm 依赖）：

```powershell
node tools/poc-intro/build.mjs --jdk '<Java 21目录>' --classpath-file '<现有安全javac参数文件>' --work '<构建目录>' --test --preview --table-texture '<ultimate_table_top.png>'
```

参数文件只读取 `-classpath` 后的库路径，不读取启动器配置或凭据。可复用此实例 `tools/poc-cursor/build/javac.args`。输出 JAR 在指定构建目录，测试类不打入模组。`--preview` 输出 PNG 与 GIF；背景和字体为离线示意，玩家立绘为明确标注的示例，不能代替实机验收。

验证包括 Java 21 编译、1334 项原序章断言、1034 项第一章剧情/翻译键/客户端文本解析/分支/中英布局/冻结状态断言、15778 项手册断言、真实 NBT v1/v2/v3 往返，以及已安装 API 和 Mixin 目标签名。翻译迁移前后的5张第一章排版预览逐字节一致。没有启动 Minecraft；真实皮肤、机器界面、JEI 跳转、资源重载及生存流程需由玩家重启验收。

科技手册使用原生三栏界面与 JEI 搜索/配方跳转，51 个模组族与操作导航，共52分类，本体与附属合并。当前4631条目录含732个操作主题，介绍机器、机制与重要功能物品，包含任务未提及的设备；变体不算独立篇数。42项按键随当前设置显示，支持长文翻页；143张原模组图可放大；详细维护与来源见 [manual/README.md](manual/README.md)。旧档可用 `/pocmanual` 找回手册，不补播剧情。手册使用本 JAR 和已安装 JEI。

## 第一章结尾：第一件造物

在现有 9×9 配方中制作并取出 `minecraft:crafting_table` 后进入剧情，普通取出和 Shift 合成都支持。触发在物品交易完成后的安全玩家刻开始，原版关闭容器流程会归还鼠标上的物品；不会消耗工作台，也不会替玩家完成流体交换。拾取、拆方块、JEI 取物和复制流体产物不触发合成挂钩，创造/旁观模式不触发。无需等到手动确认第一章结尾任务。

沿用序章的真实玩家立绘、非人形 ECHO、逐字音效、选项和分页。第一章在当前地点保持第一人称与原朝向，不重演苏醒、坐下或环顾。剧情从制作小工作台唤回一段事故前的记忆，过渡到用终极工作台换复制流体；主角心疼陪伴自己苏醒的 9×9 大工作台，ECHO 安慰接下来很长一段时间用不到。随后自然说到普通工作台的一变二复制和下一阶段的矿物、能源、自动化。选择只影响对话，不改任务、奖励或科技解锁。

**第一章流程**编辑实例根目录 `config/poc-intro/chapter1.json`。`nodes` 中的 `text` 是翻译键，例如 `poc_intro.story.chapter1.complaint`；`speaker` 为 `self` 或 `system`；`next` 指向另一节点的 `id`，`end` 结束；`choices` 中每项也使用 `text` 翻译键及 `next`。`first` 是起始节点，`labels` 的值也是翻译键。JSON 不直接写中英正文。保存 UTF-8、合法 JSON，不支持注释；服务端在下次开播时读取流程并发送给对应客户端，已完成者不会因修改而补播。

**剧情文本**统一编辑 `kubejs/assets/rain/lang/zh_cn.json` 和 `en_us.json` 中相同的翻译键。修改现有文本后按 `F3+T` 重载客户端资源，无需重编译 JAR；逐字播放、选项长度、分页、角色名及结尾文字均先通过客户端原生 `I18n` 翻译，跟随游戏语言及资源包覆盖。联机各客户端需安装对应语言文件并重载，服务端只同步流程和翻译键。构建脚本从这两份语言文件提取剧情条目，自动打包到 JAR 的语言资源作为默认回退，同时给离线预览和回归检查使用；不另外维护一份正文。新增剧情节点时也要补齐同键中英文。

`src/main/resources/assets/poc_intro/chapter1.json` 是随 JAR 附带的初始流程，只在外部文件不存在时复制出来；发布默认流程时同时更新这份源码。外部文件最大 32767 字符，节点最多128个，翻译键必须有效、跳转目标存在且所有分支能结束。构建时检查默认流程的每个翻译键是否中英齐全；流程错误会记录日志并放弃此次锁定，不覆盖作者文件，修好后重新登录可重试。

首次安装本功能后，每位玩家登录时先读取 FTB 的队伍任务记录。工作台任务 `180E8919165FF169`、收集任务 `2A074D4057754076` 或第一章结尾 `2ABCB692F4717BC5` 已完成的旧玩家直接标记为跳过，之后重做工作台、重登或任务重置均不补播。尚未完成者正常触发一次。标记与待播放/已完成记录保存在原 `data/poc_intro.dat`，兼容旧版飞行与手册领取数据；不额外授予飞行。新触发后若断线中断，会保留待播放记录，重登后在安全地点从头继续；这不改变序章严格不补播的规则。

序章正式演出和第一章剧情期间使用原生 `ServerTickRateManager.setFrozen(true)` 冻结整台服务器的世界，暂停怪物、世界时间及正常方块刻；对话玩家的输入锁定和伤害拦截继续保留。单机冻结整个世界，联机也会影响同服其他玩家所在维度。多个玩家同时对话时，最后一位离开才恢复进入前的冻结状态；本来已 `/tick freeze` 的世界保持冻结。正常结束、断线、换维度、异常和超时均释放自己的冻结占用。准备新世界岛屿时先允许模板生成，找到工作台开始正式序章时才冻结。

新增合成挂钩针对本包 Extended Crafting 7.0.9 的实际输出槽与终极工作台快速移动返回值：该输出槽不发布常规 `ItemCraftedEvent`，Shift 路径传给 `onTake` 的栈可能已为空，因此两条路径均需处理。FTB Quests 2101.1.36 用于旧存档进度基线。翻译键格式对应网络协议3，同服客户端需要安装相同更新后的 JAR。

完整退出并重启 Minecraft 才能加载 JAR 更新。验收应覆盖：未完成玩家普通/Shift 合成、剧情期间怪物和昼夜停止、两条对话分支及原朝向恢复、旧档已完成者重复制作不播、断线解冻、原已冻结世界保持、普通工作台投入复制流体后实际一变二。离线测试不替代以上游戏验证。
