# 创世之径 · 客户端光标

Minecraft **1.21.1** / NeoForge **21.1.255** / Java **21**。将 `poc-cursor-1.0.0.jar` 放入客户端 `mods` 后重启，主菜单、背包、任务书等 GUI 自动使用星核与半透明青蓝双环光标，点击产生短暂光环。无需单独启用资源包。

![光标与动画静态预览](preview.png)

光标48×48、热点 **(24,24)**。中间保持原星核、四向定位刻线和微型刻线；内外环均为完整半透明青蓝圆环#58D9EA，边缘平滑。外环半径17.5px、宽2px、alpha140/255（约55%不透明度），内环半径10.25px、宽1.3px、alpha110/255（约43%）。两环之间铺同色透明薄膜，alpha20/255（约8%不透明度）。**中心白点就是实际点击位置**，内环以内仍透空。左键青蓝、右键薄荷、中键琥珀，默认点击动画420ms，最多12个同时显示。上图为同一PNG的3倍结构与三种背景上的原尺寸静态预览。

用户游戏体验后指定此次简化方向，外围装甲和控制舱已改为圆环，原青紫断开内轨道也替换为完整青蓝内环。中心半径8.5px内的RGBA像素与上版逐点一致，星核和定位刻线的所有不透明像素保持原字节；Java代码、热点和动画不变。

本轮设计文档、独立素材与静态 QA 见 `design/cursor-star-core-2026-10-09/`。素材生成器是可编辑的几何源，PNG 本体仅用标准库；静态预览使用 Pillow（本轮复用 Codex 内置 Python）。`preview.html` 提供中心热点的浏览器指针预览。

## 兼容方式

- 独立客户端模组，服务器无需安装，没有网络请求、数据包或物品注册。
- 使用 NeoForge 的输入观察和渲染事件；不取消点击，不替换输入回调，不调整鼠标模式或位置。不修改配方、任务、按钮、音效和存档。
- FancyMenu 3.9.14 的文本、缩放及自定义 PNG 光标优先，退出该状态后恢复整合包定位环。可选适配读取其光标选择状态，在公开 tick 事件前后同步观察结果；不会改写其选择队列。当前启动环境的 GLFW 位于 bootstrap 层，单用公开跟踪接口会漏记，因此适配还依赖该版本的内部字段。字段或接口不兼容时停止替换并保留点击动画；没有 FancyMenu 时可独立运行。
- 普通 GUI 指针在每帧结束时重新应用，覆盖 FTB 任务页切换直接重置 GLFW、但跟踪缓存未更新的情况。可选读取 FTB Library 的公开光标选择字段并调用其公开接口，保留文本、手形、拖动和缩放光标；不改写 FTB 的选择字段。该接口不兼容时让位给 FTB。
- 失焦、加载覆盖层、关闭 GUI 时停止替换；屏幕切换和 GUI 缩放清空旧点击动画。第一人称世界画面保留正常鼠标捕获和准星。
- 光标创建失败时保留普通光标；只释放自己的原生句柄。原生图像缓冲在创建结束后释放，退出游戏时释放光标。

个人设置位于自动生成的 `config/poc-cursor-client.toml`：`customCursor`、`clickEffects` 和 `durationMs`（100–1000）。关闭 `clickEffects` 可停用动画；关闭 `customCursor` 可保留其他光标模组的行为。删除本模组并重启即可卸载。

## 构建和验证

本项目没有应用包管理器。构建使用本机已经安装的 Minecraft/NeoForge 库和 JDK 21，不下载依赖、不读取启动器账户或版本 JSON。`--classpath-file` 指向现有 javac 参数文件，仅复用 `-classpath` 一行。

```powershell
python tools/poc-cursor/build_assets.py
python tools/poc-cursor/build.py --jdk "<JDK21目录>" --classpath-file "<现有javac.args>" --test --native-test
```

素材预览命令需使用带 Pillow 的 Python；Codex 内置解释器路径可通过 `load_workspace_dependencies` 查询。构建 JAR 的 `build.py` 本身只依赖标准库。按作者要求，本轮新样式只执行编译，不运行 `--test`、`--native-test` 或游戏验收。

JAR 默认输出到 `tools/poc-cursor/build/`，不会自动覆盖游戏安装。`--output` 可指定输出文件。构建不包含测试类，ZIP 时间戳固定，可重复得到相同 SHA-256。

离线检查包括句柄所有权、第三方光标让位/恢复、失败降级、屏幕/缩放切换、10000 次点击的数量上限、动画过期、GUI 顶点朝向，及本机实际 FancyMenu 接口。`--native-test` 在隐藏 GLFW 窗口运行 100 次原生创建/设置/恢复/销毁，检查错误和鼠标模式。

`runtime_check.py` 用明确来源的**合成离线测试启动参数**建立独立整合包副本，加入仅用于测试的 `CursorProbe`，运行完整客户端、真实鼠标事件路径、文本输入、GUI 缩放、测试世界背包/JEI、物品点击/拖动、FTB Quests 和关闭界面检查。它不会打开作者存档，测试模组不进入正式 JAR。默认拒绝覆盖已有测试目录；`--restart` 仅在先前测试进程退出后复用副本，并归档旧运行记录。原始实例文件的哈希、运行记录和截图保存在忽略目录 `.cache/poc-cursor-20261009/`。

```powershell
python tools/poc-cursor/runtime_check.py --jdk "<JDK21目录>" --classpath-file "<现有javac.args>" --offline-launch-args "<由独立测试生成的离线参数文件>"
```

具体结果与边界见 `verification.json`。测试能验证列出的版本和路径，后续新增其他鼠标模组、操作系统、驱动或 NeoForge 版本仍需重新验收。
