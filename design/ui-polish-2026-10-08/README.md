## 生效

**保存游戏后退出，重新启动一次。** 这样 FancyMenu 新页面注册与 JourneyMap 动态纹理缓存都会刷新。仍沿用现有 KubeJS 自动加载，不需要额外启用资源包。

以后只改普通 KubeJS 贴图可用 F3 + T；菜单/地图主题变更建议重新启动。当前没有自动操作正在运行的游戏，也没有提交、推送或发布。

## 生成与检查

当前入口是本目录 `build_ui.py`，它复用上一版的图集几何，但只安装相对当前文件有变化的素材。默认生成候选和安装计划，`--install` 在逐项匹配候选及现有文件 SHA-256 后接入并备份。

`verify.py` 核对 PNG、JSON、原生尺寸、alpha、创造槽位、三种 GUI 尺寸下的装饰边界与列表安全区，以及全部任务依赖；使用已安装 FancyMenu 和 FTB 的真实解析器检查布局、页面注册、主题图标和文字对比度。

不要用上一版 `design/ui-tech-2026-10-08/build_ui.py --install` 重新生成皮肤，否则会覆盖本轮细节。上一版文档、素材和记录保留为历史；本目录及 `.cache/ui-polish-20261008/installation.json` 是本轮当前交付与安装记录。

## 备份与边界

本轮备份在 `.cache/ui-polish-20261008/backup/`，每个接入文件的前后 SHA-256 在 installation.json 和 installation-plan.json 中。回退时退出游戏，仅处理该清单，恢复有备份的文件；新增文件只在仍匹配本轮哈希时移除，不删除整个资源目录。

没有修改配方、脚本、任务数据、存档、模组 JAR 或个人界面配置。静态与原生文件解析通过；实际游戏的缩放、FancyMenu 多布局渲染次序、任务状态叠加、地图缓存和代表性生存流程仍需重启后验收。
